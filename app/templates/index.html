API Documentation

Base URL: /api/v1

Customers
GET /customers - List all customers
POST /customers - Create a new customer
GET /customers/{id} - Get customer details
PUT /customers/{id} - Update customer
DELETE /customers/{id} - Delete customer
Restaurants
GET /restaurants - List all restaurants
POST /restaurants - Create a new restaurant
GET /restaurants/{id} - Get restaurant details
PUT /restaurants/{id} - Update restaurant
DELETE /restaurants/{id} - Delete restaurant
Menu Items
GET /menu-items - List all menu items
POST /menu-items - Create a new menu item
GET /menu-items/{id} - Get menu item details
PUT /menu-items/{id} - Update menu item
DELETE /menu-items/{id} - Delete menu item
Orders
GET /orders - List all orders
POST /orders - Create a new order
GET /orders/{id} - Get order details
PUT /orders/{id}/status - Update order status
Delivery Partners
GET /delivery-partners - List all delivery partners
POST /delivery-partners - Create a new delivery partner
GET /delivery-partners/{id} - Get delivery partner details
PUT /delivery-partners/{id} - Update delivery partner
DELETE /delivery-partners/{id} - Delete delivery partner
Payments
GET /payments - List all payments
POST /payments - Create a new payment
GET /payments/{id} - Get payment details
PUT /payments/{id} - Update payment
Query Parameters:
  • page - Page number for pagination
  • per_page - Items per page (default: 20)
  • include_items - Include related items (true/false)
  • include_menu - Include menu items for restaurants
